🇬🇧 ENGLISH An e-commerce website project customized for ThaoLinh Mateco, supporting custom product catalog management, services, and online orders. ### 🛠 Tech Stack & Tools * **Core & Server:** WordPress, PHP, Apache (XAMPP Stack), MySQL * **Theme & Page Builder:** Astra Theme, Elementor * **Optimization & Security:** LiteSpeed Cache, `.htaccess` Configuration * **Version Control:** Git ### 🚀 Key Features & Custom Modules * **Custom Post Types:** Programmed and configured custom data structures including *Products, Categories, Services, News, Purchase Orders, and Contact Requests*. * **UI/UX Design:** Built responsive and modern page layouts using Elementor & Astra Theme. * **Performance Tuning:** Integrated LiteSpeed Cache for asset optimization and server-level caching. ### 💻 Local Installation Guide 1. **Clone Source Code:** * Move the project directory to: `C:/xampp/htdocs/thaolinhmateco` 2. **Database Setup:** * Open XAMPP Control Panel and start **Apache** and **MySQL**. * Navigate to `http://localhost/phpmyadmin/`. * Create a new Database named: `wordpress_db`. * Import the `wordpress_db.sql` file provided in the repository. 3. **Access the Application:** * **Storefront URL:** `http://localhost/thaolinhmateco/` * **Admin Dashboard:** `http://localhost/thaolinhmateco/wp-admin/`
